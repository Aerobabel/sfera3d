# 3DSFERA China Copyright User Manual Package

This folder contains the Chinese user manual package prepared for mainland China source code copyright review.

- `3DSFERA_china_copyright_user_manual_zh.docx` - editable Chinese Word manual with interface screenshots and operation notes.
- `screenshots/` - Chinese interface screenshots used by the manual.

The manual covers six major function areas: login/authentication, home/menu/role entry, 3D world and points of interaction, customer/buyer functions, player rewards and delivery, and supplier/merchant management.
