# 3DSFERA China Copyright User Manual Package

This folder contains the Chinese and English user manual package prepared for mainland China source code copyright review.

- `3DSFERA_china_copyright_user_manual_zh.docx` - editable Chinese Word manual with interface screenshots and operation notes.
- `3DSFERA_china_copyright_user_manual_en.docx` - editable English Word manual with expanded interface screenshots, product pages, pavilion sub-functions, customer/player screens, arcade screens, and operation notes.
- `screenshots/` - Chinese interface screenshots used by the Chinese manual.
- `screenshots-en/` - English interface screenshots used by the English manual.

The manuals cover six major function areas: login/authentication, home/menu/role entry, 3D world and points of interaction, customer/buyer functions, player rewards and delivery, and supplier/merchant management.
